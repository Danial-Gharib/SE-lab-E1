What this project demonstrates

Static Frontend

The application is implemented using pure HTML, CSS, and JavaScript.

Git Workflow

The project uses branches, commits, pull requests, and conflict resolution.

Automatic Deployment

GitHub Actions deploys the site automatically to GitHub Pages.

Repository Workflow

Branching Workflow Visualizer

This project follows a branch-based workflow where features are developed separately, reviewed through pull requests, merged into the development branch, and finally released through the protected main branch.

Feature Branches

feature/*

New website features, UI sections, and documentation changes are built in isolated branches.

  • feature/site-improvements
  • feature/github-pages-deploy
  • feature/project-shell
→
Integration Branch

dev

Completed feature branches are merged into dev first, so the team can review combined changes before production release.

→
Protected Branch

main

The main branch is protected and receives changes through pull requests only. This branch represents the deployable version of the project.

→
Deployment

GitHub Pages

After updates reach main, GitHub Actions builds and deploys the static frontend automatically to GitHub Pages.
